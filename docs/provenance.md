# Provenance and Compatibility

Garuda Code is an independent project. It is not affiliated with, endorsed by,
or sponsored by OpenClaude, Gitlawb, Anthropic, OpenAI, or any listed model
provider.

Garuda may provide similar user-facing workflows, such as a terminal chat
interface, slash commands, provider selection, tool execution, and session
management. Those are general product ideas and compatibility goals. Garuda's
source code, command metadata, TUI implementation, documentation, and visual
identity are maintained as original work.

Garuda does not bundle OpenClaude or Claude Code source code, screenshots,
logos, pixel art, private assets, or copied documentation. Provider names and
API endpoint references are used only to identify compatibility targets and
remain subject to their respective owners' terms.

## Brand assets

Only use the attached Garuda/Astra artwork in a public release if you created
it, commissioned it with redistribution rights, or otherwise have a license
that permits commercial and open-source redistribution. A generated image is
not automatically free of third-party rights. Keep unverified artwork out of
the package and use the original text mark in the TUI instead.

This document is a project policy, not legal advice. Review the licenses and
terms for any external dependency, provider, font, icon, or image before
redistributing it.
